Firmware update

Local CORE OTA · inactive firmware slot

Requires one-time USB installation of the dual-slot firmware. This is a BENCH-ONLY update path on the controller's private Wi-Fi AP. It does not install WLED, Android, Studio, or an entire GitHub ZIP. Select the CORE application .bin. User zone settings stay in NVS.
